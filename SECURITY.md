# Security Policy

## Reporting a vulnerability

If you discover a security vulnerability in SALUD 360 ECUADOR, please report it responsibly:

- Do not open a public Issue describing the vulnerability.
- - Instead, open a private security advisory through GitHub's "Security" tab for this repository, or contact the maintainer directly.
  - - Include as much detail as possible: steps to reproduce, affected component, and potential impact.
   
    - We will acknowledge reports as quickly as possible given this is a volunteer-maintained, early-stage project, and work with you to understand and address the issue.
   
    - ## Scope
   
    - This project is in an early design and prototype stage. It does not currently process real patient data or operate in any production healthcare environment. Reports related to the proposed architecture, dependency vulnerabilities, or the codebase as it grows are welcome.
   
    - ## Data protection
   
    - No real personal data, health data, or credentials should ever be present in this repository. If you find such data committed by mistake, please report it immediately using the private channel above so it can be removed.
   
    - ## Supported versions
   
    - The project does not yet have tagged releases. Security reports should target the `main` branch.
