# Contributing to SALUD 360 ECUADOR

Thank you for your interest in contributing to this project. SALUD 360 ECUADOR is an open-source, early-stage initiative, and contributions of all kinds are welcome.

## Ways to contribute

- Software development (backend, frontend, infrastructure).
- - UI/UX design.
  - - Technical and user documentation.
    - - Research on healthcare administrative workflows in Ecuador.
      - - Testing and quality assurance.
        - - Architecture review.
          - - Interoperability proposals (e.g. HL7 FHIR).
            - - Accessibility and user experience.
             
              - ## Before you start
             
              - 1. Check open Issues to see if someone is already working on what you want to do.
                2. 2. For a new idea or significant change, open an Issue first to discuss it before writing code.
                   3. 3. Keep pull requests focused on a single change when possible.
                     
                      4. ## Development setup
                     
                      5. The project is in an early design and prototype stage. See the README for the proposed architecture (React/TypeScript frontend, Python/FastAPI backend, PostgreSQL database). Setup instructions will be expanded as the codebase grows.
                     
                      6. ## Data and privacy
                     
                      7. Do not commit real patient data, personal data, or credentials of any kind. Use synthetic or anonymized data only. See `docs/data-protection.md` for details.
                     
                      8. ## Pull requests
                     
                      9. 1. Fork the repository and create your branch from `main`.
                         2. 2. Make your changes with clear, descriptive commits.
                            3. 3. Add or update tests and documentation where relevant.
                               4. 4. Open a pull request describing what the change does and why.
                                 
                                  5. ## Code of conduct
                                 
                                  6. By participating in this project you agree to follow our Code of Conduct (see `CODE_OF_CONDUCT.md`).
                                 
                                  7. ## Questions
                                 
                                  8. If you have questions, open a Discussion or an Issue. Thank you for helping build open digital infrastructure for healthcare coordination in Ecuador.
                                  9.
